Does this page use tables? If so, for what purpose?
Generally, no. Nike uses modern layout techniques like Flexbox and CSS Grid instead of traditional HTML tables for product presentations. Tables are primarily reserved for technical data, such as "Size Charts" in the footer or product details.
c.
Does this page use CSS? If so, for what purpose?
Yes, quite commonly. It's used for its minimalist page layout, high-quality typography (Nike's signature bold fonts), and responsive design that ensures the site looks good on every device
d.
Is this page appealing or unappealing? List three reasons.
Appealing.
  • 1.Minimalist design: The simple use of white space allows products to stand out without distracting elements.
  • 2.Clear Purpose: The purpose (shopping and brand identity) is immediately clear from the moment the page loads.
  • 3.Simplicity: The descriptions are extremely clear, making it very easy for the user to learn to navigate and find what they need.

Notion Unappealing
https://www.notion.com
a.
What is the URL of the website?
https://www.notion.com
b.
Does this page use tables? If so, for what purpose?
Yes. Tables (or table-like CSS structures) are used for organizing complex information, such as the "Savings Calculator" and comparison lists of features and pricing
c.
Does this page use CSS? If so, for what purpose?
YesIt is used for complex page layouts, managing a huge density of information, and styling various interactive UI elements like the "night shift" theme or AI agent icons
d.
Is this page appealing or unappealing? List three reasons.
Unappealing.
  • 1.Overwhelming Density: The page presents too many features (Docs, Projects, AI, Mail, etc.) at once, which can be "scary" for new users
  • 2.Visual Strain: The layout is cluttered with numerous headings and usage examples (Teams, Initiatives, Training), making it difficult to see
  • 3.Ambiguous Purpose: Because it tries to be "everything" (an "AI everything app"), it is difficult to quickly understand its core service
e.
If this page is unappealing, what would you do to improve it?
To improve the page, I would simplify it by using more blank space on the homepage and grouping features into separate, clickable tabs instead of listing them all on the main landing page. A single, clear primary call to action would help reduce the "intimidating" feeling of having too many options
